# AI in Finance – Lab Notebooks

Hands-on labs using free, open-source tools. Every lab runs in Google Colab: no installation needed.

| Lab | Topic | Open in Colab |

| 02 | Credit scoring: models, scorecards, SHAP explanations and fairness | [![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/RVP-ai/ai-finance-labs/blob/main/labs/02_credit_scoring.ipynb) |

More labs will be added during the semester.

## How to use a lab

1. Click the **Open in Colab** badge (sign in with a Google account).
2. **File → Save a copy in Drive**, so your work is saved.
3. **Runtime → Run all.**
4. Answer the exercises, then **File → Download → Download .ipynb** and submit it as instructed.

## Data

`data/credit_default.csv`: Default of Credit Card Clients, UCI Machine Learning Repository.
Yeh, I. (2009). *Default of Credit Card Clients* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C55S3H
(30,000 customers; the `ID` column was removed and the target renamed to `DEFAULT`.)
